## 🎨 Design System Features

### Colors
- **Primary**: Amber (400-600) for accents and CTAs
- **Base**: Slate (50-900) for backgrounds and text
- **Semantic**: Success, warning, error ready to add

### Typography
- **Headings**: Sora font family (bold, modern)
- **Body**: Inter font family (clean, readable)
- **Mono**: Geist Mono for code (if needed)

### Spacing
- **Consistent Scale**: 4px base unit
- **Section Padding**: py-20 lg:py-32
- **Container**: Centered with max-width
- **Gaps**: Consistent grid and flex gaps

### Animations
- **Fade In**: Smooth entrance animations
- **Slide Up/Down**: Section reveals
- **Scale**: Hover effects on cards
- **Bounce Subtle**: Floating elements

### Components
- **Buttons**: 4 variants, 3 sizes, rounded options
- **Cards**: Flexible with header, content, footer
- **Badges**: Multiple styles for tags and labels
